# NPC Value System

## Shared values (all NPCs, 0-1 scale)
- trust: willingness to reveal lore to player
- awareness: felt sense something is wrong with the world

## Faction-specific values (0-1 scale)
- Ashkeep: certainty (confidence in own records)
- Tidewall: isolation (time since recognized as individual)
- Fornholt: coherence (clarity of pattern-recognition)
- Duskfield: restraint (proximity to breaking silence rule)

## Memory (per-NPC, saved to JSON)
- met_player: bool
- topics_revealed: list of strings  
- last_interaction: string
- triggered: list of triggered events
